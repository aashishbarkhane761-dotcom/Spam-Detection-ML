# 🛡️ SMS & Email Spam Detection System

A Machine Learning powered Web Application built using Python, Scikit-Learn, and Streamlit to detect spam messages in real-time.

## 📌 Features
- Classifies input text as **Spam** or **Safe Message**.
- Lightweight and fast prediction using Multinomial Naive Bayes.
- User-friendly web interface created with Streamlit.

## 🛠️ Project Structure
- `app.py`: Main application interface written in Streamlit.
- `model.pkl`: Pre-trained Naive Bayes Classification Model.
- `vectorizer.pkl`: CountVectorizer feature extractor for text preprocessing.
- `requirements.txt`: Python package dependencies for deployment.

## 🚀 How to Run
1. Clone the repository:
   ```bash
   git clone [https://github.com/aashishbarkhane761-dotcom/Spam-Detection-ML.git](https://github.com/aashishbarkhane761-dotcom/Spam-Detection-ML.git)
   2. Install dependencies:
   pip install -r requirements.txt

3. Launch Streamlit app:
   streamlit run app.py
